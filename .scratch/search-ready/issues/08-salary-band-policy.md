# Salary / band policy

Type: grilling
Status: resolved
Blocked by:

## Question

When a loop asks for a number, what is the rule — name a floor, only apply to public ranges, or wait for the posting?

## Answer

Do not name a figure first. If they ask: the posting’s range, or walk. Only enter loops that improve current total compensation. The euro floor is not written in the map or the site; it stays in the candidate’s head.
